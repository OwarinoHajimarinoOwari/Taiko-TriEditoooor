TJAエディター 操作方法・仕様

基本操作とショートカット

  • Space

    プレビュー画面にフォーカスがある時、楽曲の再生・停止を行います。

  • Alt / Opt

    テキストエディタで編集中に押すと、カーソルをプレビュー画面に移動（フォーカス）させます。

  • Alt / Opt + U

    本家風UIモード(FHD)と通常プレビューを切り替えます。

  • Alt / Opt + A

    オートプレイ機能の ON / OFF を瞬時に切り替えます。

  • Alt / Opt + Wheel

    マウスホイールを上下に回転させると、プレビューの波形やノーツ間隔を拡大・縮小できます。

  • ↑ / ↓

    プレビュー画面にフォーカスがある時、一番最初、または一番最後の小節に移動します。

  • ← / →

    プレビュー画面にフォーカスがある時、前後の小節に移動します。

譜面編集・プレビュー連携

【小節ジャンプ機能】

エディタの左端にある行番号（Gutter）をクリックすると、その行に対応する小節へプレビューが一瞬でジャンプします。
また、プレビュー画面中央下部にある「小節番号表示」を直接クリックし、数字を入力してEnterを押すことでも指定の小節へ移動できます。

【音符ハイライト機能】

テキストエディタのカーソル（入力位置）がある場所の音符は、プレビュー画面上で水色の太いグリッド線としてハイライトされます。長複合などを編集する際、今どの音符を触っているのかが視覚的にわかります。

仕様・高度な特徴

【超軽量なオートプレイ合成】

オートプレイをONにして再生を開始すると、譜面内の全ての効果音（SE）がミリ秒単位で計算され、一時的な「1本のWAVオーディオ」として内部で事前合成されます。
この技術により、秒間数百打を超えるような超高密度なギミック譜面であっても、ブラウザ上でカクつくことなく非常に滑らかに再生されます。

【オーディオ波形の表示】

設定から「波形表示」をONにすると、読み込んだ楽曲の音量波形がレーン上に描画されます。音声のタイミングを目視しながらノーツを配置・微調整できるため、高精度な譜面作成が可能です（波形表示中は、強制的に「見た目BPM固定」が適用されます）。
